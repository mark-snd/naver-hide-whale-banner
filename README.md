# 네이버 웨일 배너 숨기기

네이버 메인에 표시되는 웨일 브라우저 설치 안내 배너를 숨기는 간단한 브라우저 확장 프로그램입니다.

## 동작 방식

- 네이버 페이지가 열릴 때 숨김 쿠키 두 개를 설정합니다.
- 상단·하단 배너 요소는 CSS로도 숨깁니다.
- 대상 페이지는 `https://www.naver.com/*`입니다.
- 쿠키 만료일은 방문할 때마다 1년 뒤로 설정됩니다.
- 별도 권한이나 외부 서버 통신은 사용하지 않습니다.

## 설치 방법

1. 이 저장소를 내려받아 압축을 풉니다.
2. 브라우저의 확장 프로그램 관리 페이지를 엽니다.
3. 개발자 모드를 켭니다.
4. **압축해제된 확장 프로그램을 로드**를 누릅니다.
5. 압축을 푼 폴더를 선택합니다.

## 파일 안내

- `manifest.json`: 확장 프로그램 설정
- `hide.js`: 숨김 쿠키 설정
- `hide.css`: 배너 요소 숨김 규칙

## 참고

네이버가 쿠키 이름이나 배너 요소를 변경하면 동작하지 않을 수 있습니다. 이 확장 프로그램은 현재 파일에 지정된 선택자와 쿠키 이름을 기준으로 동작합니다.
